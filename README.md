# 🚀 Portofolio Siswa SMK TKJ (Teknik Komputer & Jaringan)

Website portofolio pribadi bertema **Kreatif & Vibrant** yang dirancang khusus untuk siswa SMK jurusan **TKJ**. Dibangun dengan **HTML5**, **Tailwind CSS**, dan **Vanilla JavaScript** tanpa perlu instalasi tools rumit (bisa langsung dibuka di browser).

---

## 📂 Struktur File

```text
portfolio-tkj/
├── index.html     # File utama website portofolio
└── README.md      # Panduan penggunaan & kustomisasi
```

## ✨ Fitur-Fitur Utama

1. **Desain Kreatif & Vibrant**:
   - Skema warna gradasi modern (Purple, Pink, Cyan, Amber).
   - Efek glow dan kartu kaca (*glassmorphism*).
   - Responsif 100% (nyaman dibuka di HP, tablet, maupun laptop/PC).

2. **Bagian Portofolio Lengkap**:
   - **Hero Section**: Badge status siswa SMK, headline menarik, kartu profil animasi.
   - **Tentang Saya**: Cerita latar belakang ketertarikan di dunia jaringan & komputer.
   - **Keahlian (Skills)**: Jaringan dasar (crimping, subnetting), MikroTik/Cisco, Hardware PC, Linux Server, serta tools sehari-hari.
   - **Projek Praktik Lab**: Dilengkapi **filter kategori interaktif** (Semua, Jaringan, Hardware, Server).
   - **⚡ Mini Terminal Lab TKJ (Interaktif)**: Pengunjung bisa mengetikkan perintah Linux/jaringan seperti `whoami`, `ping`, `ip a`, `subnet`, atau `clear` secara langsung!
